# HaXX0rBunny Portfolio

[포트폴리오 열기](https://haxx0rbunny.github.io/)

C++ 게임플레이, 렌더링, 자체 엔진과 Unreal Engine 도구 개발 작업을 정리한 정적 웹사이트입니다. 한국어와 영어를 지원합니다.

## 대표 프로젝트

- [Dynamic OverAnimation](https://haxx0rbunny.github.io/overanimation.html): 3인 팀으로 제작해 Fab에 출시한 애니메이션 변형 플러그인
- [GameTechLab3rd](https://haxx0rbunny.github.io/gametechlab.html): C++/DirectX 11 자체 엔진, 임포스터 최적화, 독립 실행 빌드
- [Edge Drive](https://haxx0rbunny.github.io/index.html#project-1): 최종 3인 팀의 액션 게임, 스테이지, 캐릭터, 시간 제어


## 콘텐츠 위치

| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 메인 화면, 프로젝트 카드와 상세 모달, 영문 프로젝트 내용 |
| `locale.js`, `project-content.ko.js` | 공통 UI와 메인 프로젝트의 한국어 내용 |
| `overanimation.html`, `overanimation.ko.js` | 플러그인 설명과 한국어 내용 |
| `gametechlab.html`, `gametechlab.js`, `gametechlab.ko.js` | 자체 엔진의 주차별 구현과 실행 기록 |
| `style.css` | 공통 스타일과 반응형 배치 |

자체 엔진 링크는 `#week05/evidence`, `#week09/implementation`처럼 주차와 탭을 함께 지정할 수 있습니다. 기존 `#week05` 링크도 지원합니다.
